# دیدار

اتاق جلسه در مرورگر، با PHP. گروه کوچک مستقیم به هم وصل می‌شود. گروه بزرگ از سرور اوبونتوی خودتان برای صدا و تصویر استفاده می‌کند.

[English](README.md)

## پیش‌نیاز

**سرور اوبونتو**

- اوبونتو با دسترسی root
- دامنه‌ای که رکورد A آن به IP همان سرور اشاره کند
- یک ایمیل برای گواهی HTTPS
- این پورت‌ها باز باشند: ۲۲، ۸۰، ۴۴۳، ۳۴۷۸ روی TCP و UDP، ۵۳۴۹ روی TCP، ۷۸۸۱ روی TCP، و UDP از ۴۹۱۵۲ تا ۴۹۹۹۹ و از ۵۰۰۰۰ تا ۶۰۰۰۰

**هاست اشتراکی**

- PHP 8 و MySQL
- HTTPS
- فقط برای گروه کوچک. صدا و تصویر مستقیم بین مرورگرها رد و بدل می‌شود

## نصب روی اوبونتو

پروژه را روی سرور بگذارید، وارد همان پوشه شوید و اجرا کنید:

```bash
sudo bash ubuntu.sh --domain meet.example.com --email you@example.com
```

ورود مدیر اختیاری است: `--admin-user admin --admin-pass 'your-password'`. اگر رمز را ننویسید، اسکریپت یکی می‌سازد و آخر کار چاپ می‌کند.

اسکریپت وب‌سرور، PHP، پایگاه داده، گواهی، و سرویس صدا و تصویر را نصب می‌کند. حساب مدیر را می‌سازد و بعد فایل نصب وب را پاک می‌کند.

سپس `https://meet.example.com/` را باز کنید و وارد شوید. در تنظیمات فقط تعداد کم یا تعداد زیاد را انتخاب کنید. آدرس‌ها از قبل پر شده است.

اجرای دوباره، پایگاه دادهٔ دیدار را پاک می‌کند و از نو نصب می‌کند. بقیهٔ برنامه‌های سرور می‌مانند.

## نصب روی هاست اشتراکی

یک پایگاه دادهٔ خالی بسازید، فایل‌ها را بارگذاری کنید و این نشانی را باز کنید:

```text
https://your-domain/install.php
```

صفحهٔ نصب تا وقتی زبان دیگری انتخاب نکنید انگلیسی است. بعد از نصب موفق، همان صفحه خودش و فایل پایگاه داده را پاک می‌کند. حالت ارتباط را روی تعداد کم بگذارید.

## داخل برنامه

- زبان را موقع ورود انتخاب کنید و بعداً از پروفایل عوض کنید. زبان تازه یک فایل در `lang/` است.
- تاریخ‌ها با تقویم و منطقهٔ زمانی تنظیمات نشان داده می‌شوند.
- قدرت رمز در تنظیمات است: کم، متوسط، زیاد.
- تعداد آنلاین از خود برنامه است. پردازنده، حافظه و پهنای باند وقتی دیده می‌شود که سرور اجازهٔ خواندن آن‌ها را بدهد.
- از تنظیمات می‌شود بکاپ کامل پایگاه داده را گرفت.
- تنظیمات رلیز گیت‌هاب را چک می‌کند و با تأیید شما فایل‌های برنامه را عوض می‌کند. پایگاه داده، `config.local.php` و فایل‌های بارگذاری‌شده می‌مانند.
