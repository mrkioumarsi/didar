# دیدار

دیدار برنامهٔ جلسه در مرورگر است و با PHP نوشته شده. افراد وارد اتاق می‌شوند، صحبت می‌کنند، دوربین را روشن می‌کنند، صفحه را به اشتراک می‌گذارند، روی تخته می‌نویسند، عکس و ویدیو و PDF می‌گذارند و چت می‌فرستند. گروه کوچک مستقیم از مرورگر به مرورگر وصل می‌شود. گروه بزرگ صدا و تصویر را از سرور مدیایی می‌فرستد که همین پروژه روی اوبونتوی خودتان نصب می‌کند. سرویس جلسهٔ بیرونی در کار نیست. حساب‌ها، اتاق‌ها، چت، ضبط‌ها و تنظیمات در پایگاه دادهٔ خودتان می‌ماند.

ورود، زبان، تقویم و تعداد افراد آنلاین داخل خود برنامه است. از تنظیمات می‌شود بکاپ کامل پایگاه داده را گرفت و نسخهٔ جدید را از رلیز گیت‌هاب نصب کرد.

## پیش‌نیاز

- اوبونتو با دسترسی root
- دامنه‌ای که رکورد A آن به IP عمومی همان سرور اشاره کند
- یک ایمیل برای گواهی HTTPS
- این پورت‌ها روی IP عمومی باز باشند و اگر سرور پشت NAT است به IP خصوصی فوروارد شوند: ۲۲، ۸۰، ۴۴۳، ۳۴۷۸ روی TCP و UDP، ۵۳۴۹ روی TCP، ۷۸۸۱ روی TCP، و UDP از ۴۹۱۵۲ تا ۴۹۹۹۹ و از ۵۰۰۰۰ تا ۶۰۰۰۰

## نصب

روی سرور این را اجرا کنید. اول نسخه را دانلود می‌کند، بعد نصب می‌کند:

```bash
wget -qO didar.tar.gz https://codeload.github.com/mrkioumarsi/didar/tar.gz/refs/tags/v1.1.0 && tar -xzf didar.tar.gz && cd didar-1.1.0 && sudo bash didar-install.sh --domain meet.example.com --email you@example.com --admin-user admin --admin-pass 'your-password'
```

`ubuntu.sh` همان نصب‌کننده را اجرا می‌کند. نام کاربری و رمز مدیر را در همین دستور بگذارید. رمز نصب حداقل ۸ نویسه است. اگر `--admin-pass` را ننویسید، اسکریپت یک رمز می‌سازد و فقط یک بار در پایان چاپ می‌کند. اجرای بدون ترمینال `--confirm-wipe` هم می‌خواهد.

اسکریپت وب‌سرور، PHP، پایگاه داده، Coturn، LiveKit، گواهی، و سرویس صدا و تصویر را نصب می‌کند و حساب مدیر را می‌سازد. سایت‌های موجود Nginx می‌مانند. تمام پایگاه‌داده‌های MariaDB روی همان ماشین پاک می‌شوند.

سپس `https://meet.example.com/` را باز کنید و وارد شوید. در تنظیمات فقط تعداد کم یا تعداد زیاد را انتخاب کنید. آدرس‌ها از قبل پر شده است.

## به‌روزرسانی

پایگاه داده، `config.local.php` و فایل‌های بارگذاری‌شده می‌مانند.

از تنظیمات رلیز گیت‌هاب را تأیید کنید. روی سرور:

```bash
sudo didar-update
```

## نصب مجدد همین نسخه

پایگاه داده، پیکربندی و آپلودها می‌مانند و فایل‌های همین رلیز گیت‌هاب دوباره گذاشته می‌شوند. از تنظیمات «نصب مجدد نسخه فعلی» یا:

```bash
sudo didar-reinstall
```

سروری که از قبل روی ۱.۱.۰ است همین مسیر را می‌رود.

## حذف

دو حالت. اسکریپت تا وقتی کلمهٔ تأیید را ننویسید چیزی پاک نمی‌کند، مگر `--yes` بدهید.

فقط دیدار (پایگاه داده و کاربر دیدار، فایل‌ها، سایت Nginx دیدار، استخر PHP دیدار، LiveKit، Coturn و گواهی دیدار). Nginx، PHP، MariaDB، بقیهٔ پایگاه‌داده‌ها، بقیهٔ سایت‌ها، certbot، ffmpeg، SSH و UFW می‌مانند:

```bash
sudo didar-uninstall --soft
```

هرچه نصب‌کننده گذاشته، از جمله Nginx، PHP، MariaDB با تمام پایگاه‌داده‌ها، Coturn، LiveKit، certbot، ffmpeg و قوانین فایروالی که باز کرده. سایت‌ها، پایگاه‌داده‌ها و گواهی‌های دیگر همین سرور هم حذف می‌شوند. SSH و خود UFW می‌مانند:

```bash
sudo didar-uninstall --hard
```

اگر دستورها روی `PATH` نبودند، از پوشهٔ برنامه:

```bash
sudo bash /var/www/didar/didar-uninstall.sh --soft
sudo bash /var/www/didar/didar-uninstall.sh --hard
```

## NAT و رسانه

رکورد A باید IP عمومی باشد. اگر سرور پشت NAT است، پورت‌های بالا را به IP خصوصی فوروارد کنید. نصب‌کننده `external-ip` کاترن را عمومی/خصوصی می‌نویسد و IP عمومی را به LiveKit می‌دهد.

کلاینت پشت NAT از STUN روی ۳۴۷۸ و TURN روی ۳۴۷۸ UDP، ۳۴۷۸ TCP و ۵۳۴۹ TLS استفاده می‌کند. این آدرس‌ها در تنظیمات پر شده‌اند. اگر صدا یا تصویر قطع ماند، در تنظیمات ICE relay را روشن کنید تا مسیر از TURN برود.

اگر کلاینت در همان LAN سرور است و hostname عمومی را می‌زند، روتر باید hairpin داشته باشد، یا hostname به IP خصوصی resolve شود.

## داخل برنامه

- زبان را موقع ورود انتخاب کنید و بعداً از پروفایل عوض کنید. زبان تازه یک فایل در `lang/` است.
- تاریخ‌ها با تقویم و منطقهٔ زمانی تنظیمات نشان داده می‌شوند.
- قدرت رمز در تنظیمات است: کم، متوسط، زیاد.
- تعداد آنلاین از خود برنامه است. پردازنده، حافظه و پهنای باند وقتی دیده می‌شود که سرور اجازهٔ خواندن آن‌ها را بدهد.
- مدیر اتاق می‌تواند جلسه را ضبط کند. فایل روی همان اتاق می‌ماند و از کارت اتاق پخش می‌شود.
- برگهٔ فایل‌ها عکس، ویدیو و PDF را نشان می‌دهد. یادداشت روی عکس و PDF فقط برای حاضران همان جلسه است و ذخیره نمی‌شود. افراد داخل اتاق می‌توانند فایل را دانلود کنند. مدیر اتاق حذف می‌کند و می‌تواند به دیگران اجازهٔ بارگذاری بدهد.
- در تنظیمات می‌شود گواهی خودکار ماند یا کلید خصوصی، کلید عمومی، گواهی و باندل را چسباند. ذخیره، وب‌سرور را یک بار ری‌استارت می‌کند. اگر به حالت خودکار برگردید و آن گواهی نباشد، گواهی دستی سر جایش می‌ماند.
- از تنظیمات می‌شود بکاپ کامل پایگاه داده را گرفت.
- تنظیمات رلیز گیت‌هاب را چک می‌کند و با تأیید شما فایل‌های برنامه را عوض می‌کند. پایگاه داده، `config.local.php` و فایل‌های بارگذاری‌شده می‌مانند.
